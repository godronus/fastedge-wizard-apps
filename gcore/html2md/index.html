HTML to Markdown

Converts a CDN resource's HTML responses to Markdown whenever a client sends Accept: text/markdown — useful for AI agents that prefer Markdown over HTML.

What gets created:
  • One FastEdge app (proxy-wasm) running the HTML→Markdown filter.
  • It's wired directly onto your CDN resource across all three request/response hooks — no CDN rule or path scoping needed.
